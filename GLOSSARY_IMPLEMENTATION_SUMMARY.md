## How to Add Remaining Terms

### Step-by-Step Guide

1. **Open the glossary data file**:
   ```
   src/data/glossary.ts
   ```

2. **Add a new term** using this template:
   ```typescript
   {
     id: 'term-name',
     slug: 'term-name',
     term: 'Term Name',
     category: 'category-id',
     shortDefinition: 'One-sentence definition for previews.',
     fullDefinition: 'Comprehensive 40-80 word definition.',
     whyItMatters: 'Business relevance and importance.',
     howItWorks: 'Mechanism and implementation details.',
     example: 'Real-world B2B example.',
     useCases: ['Use case 1', 'Use case 2', 'Use case 3'],
     commonMistakes: ['Mistake 1', 'Mistake 2', 'Mistake 3'],
     relatedTerms: ['related-term-1', 'related-term-2'],
     synonyms: ['Synonym 1', 'Synonym 2'],
     confusedWith: ['confused-term-1', 'confused-term-2'],
     primaryKeyword: 'primary keyword',
     secondaryKeywords: ['keyword 1', 'keyword 2'],
     publishedDate: '2024-09-15',
     updatedDate: '2024-09-15',
     sources: [{ title: 'Source Name', url: 'https://source.com' }],
     faq: [
       { question: 'Question 1?', answer: 'Answer 1.' },
       { question: 'Question 2?', answer: 'Answer 2.' }
     ],
     featured: false,
     emerging: false,
     status: 'established' // or 'emerging' or 'experimental'
   }
   ```

3. **Update category term counts** in `glossaryCategories` array

4. **Build and test**:
   ```bash
   npm run build
   ```

5. **Verify the term appears**:
   - On glossary homepage
   - In category filter
   - In search results
   - On individual term page

## Content Quality Guidelines

### For Each Term:
- ✅ Write original, practitioner-focused content
- ✅ Provide real-world B2B examples
- ✅ Explain trade-offs and common mistakes
- ✅ Cite authoritative sources
- ✅ Avoid AI fluff and generic language
- ✅ Make definitions citation-worthy for AI systems
- ✅ Ensure content is independently understandable

### Content Depth:
- **Simple terms**: 500-900 words equivalent
- **Strategic concepts**: 1,000-1,800 words equivalent
- **Major concepts**: 1,500-2,500+ words where justified

## SEO & AEO Optimization

### Each Term Page Should:
- ✅ Have unique title tag and meta description
- ✅ Use semantic HTML structure
- ✅ Include structured data (ready for implementation)
- ✅ Have clear heading hierarchy
- ✅ Provide internal links to related terms
- ✅ Include author attribution
- ✅ Cite sources properly
